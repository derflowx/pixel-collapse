# Pixel Collapse

Browser prototype of a pixel transition: image → 8×16 bitmap text → per-letter squares → one large center square. Every pixel moves with split X/Y motion and staggered timing.

Open `index.html` in a browser. No build step.

Glyphs: [GNU Unifont](https://unifoundry.com/unifont/) (8×16, Latin-1), embedded as bitmap data.
